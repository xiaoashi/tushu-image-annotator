# 可选视觉辅助

图枢 V1.1 在本地 YOLOX 和人工标注之外，增加 OpenAI 兼容视觉服务适配器。可填写自己的 HTTPS Base URL、视觉模型名和 API Key。默认示例端点是华东师范大学平台，模型示例为 ecnu-max。

开始视觉辅助前，界面明确显示本次图片数量、所选图片缩略图和目标服务域名。只有用户勾选发送确认后才执行。图片先按当前工作版本的规范化方向读取，透明图合成白背景，最长边缩小到不超过 1600，再发送 JPEG 数据。没有选择的图片不会随请求发送。

模型返回中文场景说明、项目类别 ID、0—1000 坐标的候选框和可见依据/不确定性。接收器要求 JSON 结构正确，坐标有限、有正面积、未越界、类别属于当前项目，并转换成全分辨率坐标。结构不符时本图不接收新建议。自定义类别可以交给视觉模型判断，但这不保证特定物种识别准确。

人工框、已编辑框和已复核框受保护；重复运行仅替换尚未修改、尚未复核的旧视觉建议。大模型候选不写入虚构的置信度。接收后为待复核，零输出也不等于用户确认负样本。最终仍需对照原图复核。

网页输入的密钥只保留在本次服务进程内存中，不返回网页、不写入数据库、图片清单、软著材料或导出包。公开仓库的 `.env.example` 不含有效密钥，需要使用者自己准备 API。也可以自行设置 `TUSHU_VISION_BASE_URL`、`TUSHU_VISION_MODEL`、`TUSHU_VISION_API_KEY` 环境变量。本地开发私密配置位于源代码以外，不纳入交付目录。

[华东师范大学通用对话接口文档](https://developer.ecnu.edu.cn/vitepress/llm/api/completions.html)说明图片可以通过 text/image_url 消息输入。这里采用相同的 OpenAI 兼容请求结构；不要求用户安装 OpenAI SDK。

真实验证记录见 `vision-real-validation.json`。公开样例的作者、来源、许可和修改记录见 `samples/public/ATTRIBUTION.md`。这组样例只验证功能调用与保存，不用于声明精确率、召回率或专业物种鉴定能力。
